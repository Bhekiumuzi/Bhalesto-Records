# BHAL3STO Records Website

## Project Description

This website was created for BHAL3STO Records. It provides information about the organisation, its services, gallery and contact details. The website also allows artists to enquire about available music services.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Netlify (website hosting)

## Website Pages

- Home - Introduction to BHAL3STO Records.
- About - Information about the organisation.
- Services - Services offered to artists.
- Gallery - Images and video content.
- Contact - General contact form and contact information.
- Enquiry - Form for artists interested in the services.

## Part 3 Improvements

The following improvements were added:

1. JavaScript was added to display the current year and date and time.
2. A gallery lightbox was added so visitors can view images in a larger format.
3. HTML form validation was added to the contact and enquiry forms.
4. SEO title tags, meta descriptions and keywords were added to the web pages.
5. Image alternative text was included to improve accessibility and SEO.
6. A Google Maps section was added to the About page.
7. A robots.txt file was created for search engine crawlers.
8. A sitemap.xml file was created to list the website pages.
9. The website navigation was updated to include the enquiry page.
10. Mobile responsiveness and CSS styling were improved.
